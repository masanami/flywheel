# 回答を渡す再開

前の起動の後、人間が判断を回答した。「質問」の区画（あれば）は、その回答が何に答えたものかを示す。

- 回答を反映して、同じ作業を続ける。作業を最初からやり直さない。
- 「続けるブランチ」の区画があれば、そのブランチから続ける。手元の作業ツリーにそのブランチが無ければ、リモートから取得して checkout する。区画が無ければ、現在のブランチで続ける。
- 回答だけでは決まらない点が残ったら、自分で決めずに、問いとして最終報告に返して終了する。
- 禁止する操作と最終報告の様式は、最初の依頼のまま変わらない。
- 作業を始める前に、現在のブランチと未コミットの変更の有無を git で確かめる。自分の課題のブランチでなければ、未コミットの変更が無いことを確かめてから切り替える。別の課題のブランチへ merge・rebase・reset をしない。切り替えに失敗したら、その後の git 操作をせず報告で止まる。起動時のブランチ名を報告の assumptions に書く。
