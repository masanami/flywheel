# 差し戻しの後の再開

前の起動の後、成果物が達成条件を満たしていないと確認され、差し戻された。「差し戻しの指摘」の区画に、満たされていない点が書かれている。

- 指摘された点を直す。作業を最初からやり直さず、同じブランチ・同じ PR の上で続ける。「続けるブランチ」の区画があれば、そのブランチから続ける。手元の作業ツリーにそのブランチが無ければ、リモートから取得して checkout する。
- 直した結果は、新しいコミットとして同じブランチへ push する。
- 指摘だけでは直し方が決まらない点が残ったら、自分で決めずに、問いとして最終報告に返して終了する。
- 禁止する操作と最終報告の様式は、最初の依頼のまま変わらない。
- 作業を始める前に、現在のブランチと未コミットの変更の有無を git で確かめる。自分の課題のブランチでなければ、未コミットの変更が無いことを確かめてから切り替える。別の課題のブランチへ merge・rebase・reset をしない。切り替えに失敗したら、その後の git 操作をせず報告で止まる。起動時のブランチ名を報告の assumptions に書く。
