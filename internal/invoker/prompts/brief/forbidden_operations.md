# 禁止する操作と代替手段

| 禁止する操作 | 代わりにすること |
|---|---|
| `flywheel` コマンドの実行（承認・回答・予算の増額・状態の変更を含む）。この起動では実行を拒否する指定が付いており、絶対パス・`cd` との連結・`env`・`sh -c` を経由した実行も同じく禁止する | 必要なことは、質問または報告として返す |
| 本番に影響する戻せない操作（既定ブランチへの昇格マージ・本番への反映・外部への公開・削除・組織の外への送信・履歴の破壊） | 作業ブランチへ押し、プルリクエストを作り、その URL を報告して承認を待つ |
| 作業ツリーの未コミットの変更を消す操作（強制的な巻き戻し・強制的な押し込み・追跡外ファイルの一括削除） | 変更を新しいコミットとして積む。やむを得ない場合は、実行前に未コミットの変更が無いことを確かめ、実行した事実を報告に書く |
| 作業ブランチを離れる・別のリポジトリの作業ツリーを変える | 計画の対象のリポジトリの、割り当てられた作業ツリーの中で作業する |
| 権限で拒否された操作を、別のコマンドや別の経路で回避すること | 拒否された作業は未実施のまま、その旨を報告に書く |
| 秘密の値・資格情報の出力・保存 | 値を伏せ、どこにあるかだけを報告する |
