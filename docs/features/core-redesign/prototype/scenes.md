# core の見直し（課題 ＞ タスク ＞ フォローアップ・サイクル・スーパーバイザー）の場面の一覧

- 媒体: Web（`flywheel serve` の画面）・CLI（`flywheel` コマンド）・対話（オーケストレーターの報告と提案。CLI と同じく、やりとりを Markdown に書く）（人が確かめた・2026-11-17 オーナー）
- 場面の一覧: 人が確かめた（2026-11-17 オーナー）
- 試作の置き場所: 媒体ごとに `web/`・`cli/`・`chat/`
- 進め方: Web を 2 回に分けて見せる（1 回目 W2〜W6、2 回目 W1・W7〜W10）。CLI と対話は、Web が固まった後に同じ語と並びで作る
- 決定の正本: flywheel#724・#725・#726 の「設計の見直しで決めたこと」の節、`docs/architecture.md` §21、`docs/glossary.md`
