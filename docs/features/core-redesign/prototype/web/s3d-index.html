区切り S3d の試作（画面の変更点）

いまの画面（区切り S2c）から変わる所だけを作っています。対話の欄・スーパーバイザーの表示は区切り S4 なので、ここにはありません。

場面いまの画面から変わること
1. いま進められること完了の承認待ちの行が、課題の詳細ではなく、完了承認画面へ行く
2. 完了承認画面（新しい画面）確かめの結果・反映するもの・タスク・フォローアップを 1 画面で見て、承認する
3. 完了承認画面（承認した後）承認を記録した旨と、反映先へ入れる承認の案内
4. 課題（タスクのツリー）札の語が名詞の形になる。実行中の箱と、課題の見出しに、細かい進みの語が付く
5. タスクの詳細（委譲先が進めている）委譲先の実行・成果物・値で返したこと・検証・費用の区画が増える
6. タスクの詳細（検証を通って、統合先へ入れている）同上（検証の結果と、統合先へ入れる進み）
7. 課題の詳細完了の承認の区画がリンクになる／経緯が 1 行／前提の語（未解消）／不可逆操作の語／通した衝突の解消
8. 計画の承認の画面の、差し戻しの案内コマンドの例を外し、対話で伝える方法だけにする
