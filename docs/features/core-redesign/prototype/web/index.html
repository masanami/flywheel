W2 課題の詳細

  • 走っていて、あなたを待つ問いが 1 件ある
  • あなたを待つものが無い スーパーバイザーが手を打って進んでいる
  • 全部のタスクが済み、完了の承認を待っている
  • 課題の進め方を、オーケストレーターに相談する 右の欄のやりとりを見てください

W3 タスクの詳細

  • 走っている
  • 済み（検証を通って、統合先に入った）
  • 検査の失敗で、スーパーバイザーが差し戻した

W4 計画の承認

  • 計画と問いを同時に見る 問いの答えを変えると、ボタンが「作り直す」に変わります
  • 推奨と違う答えで、計画を作り直している
  • 承認して、サイクルが始まった
  • 差し戻す

W5 完了の承認

  • 確かめの結果・実物・スーパーバイザーの記録・フォローアップを見て承認する
  • 完了を承認した（反映の承認は端末か対話から）
  • 対話で「承認します」と伝える 完了と反映の両方が記録される
  • 差し戻す

W6 オーナーへの問いに回答（タスクの詳細の中）

  • 選ぶだけで答えられる問い ボタンで答えるか、オーケストレーターと相談する
  • 答えた後
  • 対話で相談して、選択肢に無い答えを伝える 右のオーケストレーターとのやりとりを見てください
  • タスクを足すと予算の上限を超える ボタンでは受けず、対話で決める

補足: 開発ではない見本

  • 課題の詳細（記事を出す）
  • タスクの詳細（図版を作る）

W8 いま進められること（最初の画面）

  • あなたを待っているものと、取り込めるもの 問いに続けて答えられ、取り込むものを選べる
  • 進められるものが 0 件

W1 課題（ツリーだけ）

  • 課題ごとの枠に、タスクのツリーを並べる 完了した課題は、下の「開く」で出る

W7 フォローアップの一覧

  • 課題をまたいで並べる 選んで、済みにする・捨てる
  • オーケストレーターに整理を頼む 右の欄のやりとりを見てください
  • 未のフォローアップが無い

W9 走っているサイクル

  • 走っている サイクルの構造と、いまの位置を出す
  • 走っていない 最後のサイクルの振り返りを出す
